# ترجمة دبّر (عربي ← English)

- `public/app/dabbar-i18n.js` : المحرّك (بيترجم كل نص بيظهر على الشاشة من القاموس عند اختيار English).
- `public/app/i18n-en.js` و `lib/i18n-en.json` : القاموس (بيتولّد تلقائيًا — متعدّلوش بإيدك).
- `t0..t4.tsv` (نصوص الواجهة) و `s0.tsv` (نصوص HTML الثابتة) و `be.tsv` (رسائل السيرفر): مصدر الترجمة، سطر لكل نص بصيغة `رقم<TAB>English` (الرقم = ترتيب النص في `segments*.json`).
- لإضافة نص جديد: ضيفه في `extra` جوه `build_dict.py` (عربي: English) وشغّل `python3 build_dict.py`.
- `{}` في النص = مكان قيمة متغيّرة (رقم/اسم). في الإنجليزي ممكن تستخدم `{1}` و`{2}` لتغيير الترتيب.
- لمراجعة أي نص لسه عربي أثناء الاستخدام: افتح التطبيق بـ English وشغّل في الـ Console: `DabbarI18n.missing()`.
