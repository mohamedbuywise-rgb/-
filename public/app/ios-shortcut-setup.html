إعداد إرسال رسائل البنك إلى دبّر

Apple لا تسمح بملف Shortcut عام يحتوي Token شخصي لكل مستخدم. لذلك نعرض لك بياناتك بعد تسجيل الدخول وتضيف Automation مرة واحدة من تطبيق Shortcuts.

بيانات الربط الخاصة بك

لا تشارك الـToken مع أي شخص. يُستخدم فقط لربط الرسائل بحسابك.

بنجيب بيانات الربط...

Webhook URL

Token

الخطوات

1. افتح Shortcuts → Automation → Message.
2. اختر مرسل البنك، ثم أضف Get Contents of URL بطريقة POST.
3. استخدم JSON: {"token":"TOKEN","sender":"اسم البنك","text":"نص الرسالة"}
4. أوقف Ask Before Running إذا ظهر الخيار، ثم اختبر برسالة حقيقية.

مهم

الربط التلقائي الكامل في الخلفية موثوق أكثر على Android. في iPhone تعتمد الأتمتة على صلاحيات وإصدار iOS، وقد يطلب النظام تأكيدًا لبعض الإجراءات.
